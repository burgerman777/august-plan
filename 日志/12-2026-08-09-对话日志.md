## 二、MVP 搭建（第一阶段）

项目路径：`C:\Users\30990\Desktop\头牟搭七\review-nfc\`

| 文件 | 用途 |
|------|------|
| `index.html` | 顾客端：碰 NFC → AI 生成好评 → 复制 → 跳平台 |
| `admin/index.html` | 商家管理：配置店铺信息，生成链接+二维码 |
| `assets/css/style.css` | 移动优先样式 |
| `assets/js/config.js` | 全局配置 + URL 参数解析 |
| `assets/js/ai-service.js` | AI 引擎：demo 模板引擎（免费）+ DeepSeek 可选 |
| `assets/js/app.js` | 顾客端主逻辑 |
| `server.js` | Express 本地开发服务器 + DeepSeek API 代理 |
| `README.md` | 项目文档 |

### 关键设计决策

- **免费 AI 方案**：纯前端模板引擎，50+ 种文案变化（4 种语气 × 8 类菜系 × 多套开头/正文/结尾），零成本即时响应
- **Demo 模式默认**：不调任何 API 也能跑，DeepSeek 可选用
- **NFC 立牌成本**：标签 ¥1-3 + 亚克力架 ¥15-30 = 单个约 ¥25，卖 ¥99-199

### 遇到的 bug

- `ai-service.js` 引用了 `CONFIG.ai` 但忘了 `import CONFIG`，导致顾客端点换一条报"生成失败"——已修复

## 三、P0 全面优化（第二阶段）

用户要求先规划再实施。写了一份完整的 33 项优化规划（P0 13 项 / P1 12 项 / P2 8 项），然后按四波实施全部 13 项 P0：

### 第一波：CSS内联 + 安全 + 品牌

- **P0-10**：60 行关键 CSS 内联到 `<head>`，完整样式异步加载
- **P0-11**：URL 参数白名单校验 + `sanitize()` 函数 + CSP meta 标签
- **P0-8**：SVG Logo（NFC 波纹+星）+ 盾牌隐私图标 + "无需登录·不获取信息"

### 第二波：商家向导 + 演示页

- **P0-12**：admin 页重写为 5 步分步向导：店名→菜系卡片→招牌菜→语气+平台→预览+生成→NFC教程
- **P0-13**：新建 `demo.html`，五种菜系一键切换展示产品效果，底部 CTA 引导创建

### 第三波：顾客体验闭环

- **P0-1**：平台深链接 `dianping://` / `imeituan://`，2秒超时自动降级网页
- **P0-2**：生成后自动复制到剪贴板 + toast 提示
- **P0-3**：激励文案栏（商家可配 "发完评价送饮料"）
- **P0-7**：剪贴板三层降级：clipboard API → execCommand → 长按手动选
- **P1-5**：去掉 demo 模式 400-1000ms 人为延迟，瞬间生成

### 第四波：技术基建

- **P0-9**：Service Worker — 静态资源 Cache-First + 页面 Network-First，回头客秒开，离线可用
- **P0-4**：analytics.js 埋点模块，5 个事件（pageview/copy/regenerate/goto/incentive_show），数据存 localStorage + 预留 Beacon API 远程发送
- **P0-6**：漏斗转化率计算（copyRate / gotoRate / estimatedReviews）
- **P0-5**：轻量实现（激励文案+品牌提示），完整留资表单留待 P1
