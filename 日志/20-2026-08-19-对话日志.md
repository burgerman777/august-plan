## 四、后续学习方向讨论（对话中）

- 用户明确：**AI 系统学习本地私密、不 push，将来做知识付费**；问「后面还需要学什么」。
- 核心判断：当前纯前端只能接「网页单」，补后端才能接「企业单」。

| 优先级 | 方向 | 为什么 |
|:--:|---|---|
| 🥇 | 后端 API 服务化（FastAPI） | 网页单→企业单的分水岭，直接解锁高价单 |
| 🥇 | Memory（Agent 记忆） | 客服/助手要记住用户，NFC 客服/掌厨可复用 |
| 🥈 | 评测 Eval | 教课信任状 + 企业单交付标准 |
| 🥈 | MCP | 低成本差异化卖点 |
| 🥉 | RAG 进阶、LangGraph | 更高价企业单 |

- 建议顺序：先后端 API → 再 Memory → Eval/MCP 穿插。
