## 五、经验记录

> 1. **数据已经是「数据+渲染分离」时，抽数据源是水到渠成的事**——index.html 早就把渲染函数和 DAYS 分开了，今天只是把 DAYS 搬出去。
> 2. **参数加载用 JSON + fetch**——AI 后续生成 JSON 最自然（v2 直接让 Agent 吐 plans/xxx.json）。
> 3. **localStorage 按 plan 隔离**——否则自己看默认计划 + 客户计划时，勾选记录会串。
> 4. **冒烟测试比只看语法强**——mock 掉 DOM 跑一遍渲染，能抓到「数据字段和渲染代码不匹配」的运行时错误。
