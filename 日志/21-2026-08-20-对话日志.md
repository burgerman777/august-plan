## 一、FastAPI 最小后端（上午）

- 建 `AI系统学习/08-backend-fastapi/`，venv + 清华镜像装 fastapi / uvicorn / httpx。
- 写 `main.py`：`/`（hello）、`/api/health`（健康检查）、`/api/chat`（DeepSeek 代理）、CORS 中间件。
- 核心认知：**CORS 是「浏览器」的限制，服务器之间没有这回事** —— 前端 → 自家后端（放行）→ DeepSeek（服务器身份）。

## 二、真实调通（踩中文编码坑）

- 英文 message 直接通；中文在命令行里被转 GBK → JSON 变非法字节，报 `error parsing the body`。
- 解法：把 JSON 写进 UTF-8 文件，`curl --data-binary @文件` 传。

## 三、流式输出（SSE）

- `/api/chat/stream`：`StreamingResponse` + async generator + `httpx.stream()` + `aiter_lines()`，逐行转发 DeepSeek 的 SSE。
- 核心：前端直调拿不到流式（wx.request 无 ReadableStream、浏览器被 CORS 拦），后端代理正好补上。

## 四、key 藏 .env

- `load_dotenv()` + `os.getenv("DEEPSEEK_API_KEY")`，`ChatRequest` 去掉 api_key 字段。
- `.env` 进 `.gitignore`（key 不进代码/前端/git），`health` 加 `key_loaded` 字段。
- 核心：**用户自备 key 是「省钱」，你出 key 才能「限流 + 订阅收费 + 接企业单」**。

## 五、部署（GitHub + Cloudflare Tunnel）

- GitHub 私有仓库 `burgerman777/ai-gateway`，只 push 代码（学习日志/.env 排除）。
- **踩坑：Render 免费档 2026 起强制绑信用卡**，不绑无法部署 → 换 Cloudflare Tunnel。
- cloudflared 下载：winget 卡 UAC → 改直接下 exe；国内直连 GitHub release 慢（117KB/s）→ `gh-proxy.com` 加速（5.84MB/s）。
- `cloudflared tunnel --url http://localhost:8000` → 公网临时 URL，`/` `/api/health` `/api/chat` 全通。

## 十一、经验记录

> 1. **后端代理 = 藏 key + 绕 CORS + 解锁流式 + 能限流**，是「网页单 → 企业单」的分水岭。
> 2. **中文命令行编码坑** —— Windows 终端转 GBK，JSON 变非法字节，用文件传 body 解决。
> 3. **流式 SSE 需要「真容器」** —— 免费 serverless（Vercel 10s 超时 / CF Pyodide）都不适合。
> 4. **国内下 GitHub release 用加速镜像** —— `gh-proxy.com` 前缀，比直连快几十倍。
> 5. **Render 2026 起免费档也要绑卡** —— 部署平台的坑要提前查。
